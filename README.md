# Sales Prediction using Python

Jupyter Notebook project based on the provided Advertising.csv dataset.

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

Open `Sales_Prediction_using_Python.ipynb` and run the cells from top to bottom.

## Dataset
Advertising.csv contains TV, Radio, Newspaper advertising expenditure and Sales.
